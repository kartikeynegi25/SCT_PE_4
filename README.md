# Task 04 – Simulating an AI Assistant

## Objective

The objective of this task is to design an AI assistant using structured prompt engineering techniques that can interact naturally with users, maintain context throughout a conversation, and provide personalized guidance.

---

## Assistant Chosen

Career Mentor AI

The assistant helps students choose career paths, recommend projects, suggest learning resources, and create personalized roadmaps.

---

## Prompt Engineering Techniques Used

- Role Prompting
- Context Retention
- Multi-turn Conversations
- Output Formatting
- Personalized Responses

---

## Features

- Student Guidance
- Skill Assessment
- Career Recommendations
- Project Suggestions
- Learning Roadmaps
- Motivational Support

---

## Skills Demonstrated

- Prompt Engineering
- AI Assistant Design
- Conversation Design
- User Experience
- Context Management

---

## Conclusion

A well-designed system prompt enables AI assistants to provide natural, personalized, and consistent conversations across multiple interactions.
